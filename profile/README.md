# Tapfiliate

Affiliate and partner program software: track referrals, automate commissions and pay your partners.

**Building an integration?** Start at **[developers.tapfiliate.com](https://developers.tapfiliate.com)**.

- [Quickstart](https://developers.tapfiliate.com/quickstart) — your first API request and tracked conversion
- [REST API reference](https://developers.tapfiliate.com/api-reference/introduction)
- [JavaScript tracking](https://developers.tapfiliate.com/tracking/javascript) and the [`@tapfiliate/tapfiliate-js`](https://www.npmjs.com/package/@tapfiliate/tapfiliate-js) package
- [MCP server](https://developers.tapfiliate.com/ai/mcp) — connect Claude, Cursor and other AI assistants to your account
- [Build with AI](https://developers.tapfiliate.com/ai/build-with-ai) — give your coding assistant our docs

Questions about your account: [help center](https://support.tapfiliate.com).
